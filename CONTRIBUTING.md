# Contributing

## Principles

Changes involving legal data, AI-generated legal analysis, source rights, privacy, or security require heightened review.

## Pull Request Expectations

Every PR should state:
- What changed
- Why it changed
- User impact
- Data impact
- AI impact
- Security/privacy impact
- Legal/compliance impact where relevant
- Tests performed

## Legal Data Changes
Do not add new legal-content sources without documenting provenance and rights status.

## AI Changes
Changes to retrieval, prompts, ranking, or answer generation should include evaluation results where practical.

# Phase 8A — retrieval foundation

Implemented:

- retrieval source kinds
- exact immutable source/version references
- authorized Ghana task scope
- bounded query validation
- deterministic SHA-256 query fingerprints
- deterministic evidence ranking
- duplicate evidence removal
- bounded result count
- generic authorized retrieval-source port
- retrieval orchestration
- grounded research packet foundation

This phase intentionally does not yet implement:

- PostgreSQL search adapters
- retrieval session persistence
- corpus rights adapter
- Firm Knowledge adapter
- Matter Document adapter
- chunk persistence
- Work Product bridge
- retrieval audit
- migrations

Those follow after repository search/index primitives are confirmed.

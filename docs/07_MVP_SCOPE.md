# MVP Scope

## Build Now
1. Approved-source ingestion
2. Case + legislation corpus
3. Metadata extraction/review
4. Keyword + semantic search
5. Ask Ghanaian Law
6. Case summaries
7. Similar-case retrieval
8. Source passage citations
9. Saved research/projects
10. Basic legal alerts
11. Research report generation
12. Admin data-quality console

## Build Later
- Private law-firm knowledge bases
- Advanced document intelligence
- Corporate compliance monitoring
- Full citation-treatment graph
- Historical point-in-time legislation
- Public API
- Advanced analytics
- Additional jurisdictions

## Explicitly Not MVP
- Lawyer marketplace/referrals
- Numerical win probability
- Full law-practice CRM
- Accounting
- Court filing
- Consumer legal representation

## MVP Quality Bar
A smaller trusted corpus with excellent retrieval is preferable to a large unreliable corpus.

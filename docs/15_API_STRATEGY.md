# API Strategy

## Goal
Eventually expose trusted legal search and structured intelligence to approved institutional customers.

## Initial Internal APIs
- Search
- Document retrieval
- Passage retrieval
- Case relationships
- Research runs
- Projects
- Alerts

## Future External APIs
- Legal search
- Authority lookup
- Case metadata
- Legislation/provisions
- Citation graph
- Grounded research (controlled)
- Change feeds

## Controls
- Authentication and scoped API keys
- Rate limits
- Tenant isolation
- Usage metering
- Source-license enforcement
- Audit logs
- Versioned endpoints

## Principle
API rights must never exceed the rights the platform has to the underlying content.

# Operations Playbook

## Legal Data Operations
- Acquire approved sources
- Review document integrity
- Correct metadata
- Resolve duplicates
- Validate citations
- Track rights/provenance

## Customer Operations
- Onboarding
- Training
- Research support
- Feedback collection
- Escalation of suspected legal-data errors

## AI Quality Operations
- Review failure cases
- Maintain evaluation sets
- Track hallucinations
- Improve retrieval
- Re-run quality tests before major releases

## Content Updates
- Schedule source checks
- Ingest new judgments
- Ingest legislative amendments
- Trigger alerts
- Re-index affected authorities

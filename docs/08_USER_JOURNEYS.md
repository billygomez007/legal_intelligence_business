# User Journeys

## Lawyer: Research an Issue
1. Sign in.
2. Ask a legal question.
3. System identifies research intent.
4. Hybrid retrieval finds approved authorities.
5. User receives synthesis with citations.
6. User opens supporting passages.
7. User explores similar/contrasting cases.
8. User saves authorities to a matter.
9. User generates a research report.

## Lawyer: Analyze a Judgment
1. Search/open case.
2. Review structured case brief.
3. Jump to relevant source passages.
4. Review cited/citing authorities.
5. Save notes and authority.

## Firm: Private Knowledge
1. Authorized admin creates workspace.
2. Firm uploads approved internal material.
3. Documents are processed into a tenant-isolated index.
4. Lawyers can search public law and private firm knowledge with clear source labels.

## Corporate: Monitor Topic
1. Define legal topics.
2. System tracks new approved materials.
3. Relevant changes trigger alerts.
4. User opens the authority and AI summary.

## Student/Public
1. Search a law/case.
2. Receive simplified explanation.
3. Open authoritative source.
4. Product displays clear legal-information boundary.

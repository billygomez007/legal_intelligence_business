# Metrics Framework

## North-Star Candidate
Weekly completed legal research sessions resulting in at least one saved or exported verified authority.

## Product
- Weekly active lawyers
- Research queries per active user
- Search success rate
- Authority open rate
- Saved authority rate
- Report generation rate
- Alert engagement
- Return frequency

## Trust
- Citation accuracy
- Unsupported-claim rate
- Metadata correction rate
- Human-review disagreement rate
- User-reported legal error rate

## Commercial
- Trial-to-paid conversion
- MRR/ARR
- ARPA
- Seat expansion
- Logo retention
- Net revenue retention
- Sales cycle length

## Data
- Verified cases
- Verified provisions
- Paragraph-level coverage
- Citation graph coverage
- OCR error rate
- Review time

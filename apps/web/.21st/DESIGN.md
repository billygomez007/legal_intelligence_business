# Legal Intelligence web design context

Professional legal research software for Ghanaian lawyers and firms. The user's selected direction is restrained navy/charcoal, blue actions, neutral document surfaces, generous whitespace and strong source traceability.

- Framework: Next.js App Router, React, TypeScript, Tailwind CSS.
- Interaction primitives: native semantic controls and Radix Dialog.
- Colors: navy navigation `#13293d`, blue accent `#285b8b`, canvas `#f6f7f9`, ink `#172b40`.
- Type: local Helvetica/Arial UI; Georgia for synthetic source passages.
- Source: `../src/app/globals.css` and `../src/components`.
- Desktop: persistent navigation and inspectable source rail.
- Mobile: dialog navigation, stacked reading regions, accessible native controls.
- Trust: distinct source, metadata, synthesis and note surfaces. Every synthetic verification badge is marked as a demo.
- Motion: minimal, reduced-motion-aware loading only.
- No decorative gradients, marketing illustrations, outcome predictions or real-looking fictional citations.

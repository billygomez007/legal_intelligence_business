# Security Policy

## Reporting
Security vulnerabilities should be reported privately to the project maintainers and should not be filed as public GitHub issues.

## Sensitive Data
Never commit:
- API keys
- passwords
- production credentials
- client legal documents
- private customer datasets
- unredacted secrets

## Security Baseline
- Secret scanning
- Dependency scanning
- Branch protection
- Required reviews
- Least-privilege access
- Tenant-isolation testing
